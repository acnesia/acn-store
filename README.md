# 🏪 ACN Store

Catalogue public et distribution officielle des applications Android ACN Development.

## 📥 Télécharger l'application ACN Store

Pour installer le store sur votre téléphone Android :

👉 **[Télécharger ACN Store (APK officiel)](https://github.com/acnesia/acn-store/releases/download/com.acn.store-v2.3.0/ACN-Store-2.3.0.apk)**

Toutes les versions et mises à jour sont disponibles dans l'onglet **[Releases](https://github.com/acnesia/acn-store/releases)**.

---

## 📱 Contenu du dépôt

Ce dépôt héberge uniquement les éléments de distribution publique :
- catalog.json : Métadonnées et catalogue des applications distribuées (versions, hachages SHA-256, liens APK).
- icons/ : Icônes officielles des applications.
- screenshots/ : Captures d'écran de présentation.
- **Releases** : Fichiers APK publics téléchargeables directement.
